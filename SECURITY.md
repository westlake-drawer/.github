# Security Policy · 安全政策

## 报告漏洞 / Reporting a vulnerability

请私下报告：在受影响的仓库使用 GitHub 的 **Report a vulnerability**，或通过组织页面联系维护者。
不要在公开 issue 中写复现步骤。

Report privately: use GitHub's **Report a vulnerability** on the affected repository,
or contact a maintainer through the organization page. Do not open a public issue
with reproduction steps.

我们会在 72 小时内确认收到，修复后再公开说明（不含复现细节）。
We acknowledge within 72 hours and publish a summary after the fix, without
reproduction details.

## 范围 / Scope

本组织的仓库与站点。列出的第三方工具由各自作者负责，本站不代为审计。
This organization's repositories and site. Listed third-party tools are the
responsibility of their authors and are not audited here.
