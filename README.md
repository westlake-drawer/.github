**Westlake Noter** is a student-led, open-source collection of course notes from
Westlake University — shared by students, open to everyone. Notes are written in
Markdown + LaTeX (KaTeX) with Mermaid diagrams. The collections below mirror the
site's **[Notes](https://westlake-drawer.github.io/notes/)** and
**[Tools](https://westlake-drawer.github.io/tools/)** sections, ranked by the
GitHub stars of each referenced repository (same order the sidebar uses).

- 🌐 **Website:** [westlake-drawer.github.io](https://westlake-drawer.github.io/)
- 📚 **Content:** [westlake-drawer/notes-index](https://github.com/westlake-drawer/notes-index)
- 💬 **Community:** [westlake-drawer/community](https://github.com/westlake-drawer/community)
- 🤝 **Join:** [membership-application](https://github.com/westlake-drawer/membership-application)
